# Alpha 预览版改版说明

参考：[Apple 首页](https://www.apple.com/)、[MacBook Pro 产品页](https://www.apple.com/macbook-pro/)。借鉴的是信息的展开方式、视觉层级和行动入口。

| 苹果官网的呈现方式 | 在学术主页上的对应修改 |
| --- | --- |
| 首屏用一句话说明核心价值 | 用「我们如何共同推理？」引出研究问题，同时呈现姓名、单位、职称与个人照片 |
| 从概览逐步深入细节 | 研究问题 → 三条研究线索 → 五篇代表作 → 完整书目与学术信息 |
| 用图形解释抽象概念 | 三个个体论辩图与一个群体图；可切换多数规则与全体一致规则，观察攻击关系的变化 |
| 每个区块集中说明一个重点 | 代表作先给出研究问题或贡献，再呈现正式英文题名、作者、期刊和年份 |
| 明确下一步行动 | 代表作附 PDF / 出版页面、DOI、可展开的 BibTeX、复制与下载入口 |
| 用字号、留白与背景建立节奏 | 系统字体、黑灰文字、蓝色链接、大标题、浅灰分区；基础研究论文用深色卡片突出 |
| 概览与详细参数分别呈现 | 代表作便于快速了解；23 条完整书目按原分类保留，支持标题、作者、刊物与年份搜索 |

## 访问方式

- 正式主页 `/` 与 `/cn.html` 保持原样。
- 英文预览版：`/alpha/`；中文预览版：`/alpha/cn.html`。
- 预览版导航提供返回正式主页的入口。
- 预览版使用独立样式、脚本与引用文件，并设置 `noindex`，避免搜索结果混入实验版。
- 照片、论文 PDF 与简历通过相对路径复用站点原有资源。

## 实现与维护

- 英文入口：`index.html`；中文入口：`cn.html`。
- 共用 `homepage.css` 与 `homepage.js`，无需构建步骤或额外依赖。
- `citations/` 中保存五篇代表作的 BibTeX，与页面中的引用内容对应。修改书目信息时需同步更新两种语言及 `.bib` 文件。
- 论文的正式题名、作者、DOI、原有书目、报告、项目和履历均保留；中文导读与英文导读是另加的内容呈现层。
- 图中的箭头表示攻击关系：三个个体图各含两条攻击边，均无环；多数规则保留三条边，形成三元环；全体一致规则不保留任何边。该图解释聚合规则的影响，未将无环性等同于可采纳性。
- 原有 Google Analytics 配置保留。排版不再依赖远程字体或 Bootstrap。
- 未启用 JavaScript 时，导航、研究背景、全部书目、引用文本与 `.bib` 下载仍然可用；示意图默认呈现多数规则。
- 包含移动端布局、键盘焦点、跳转正文、折叠菜单、状态反馈、减少动态效果与打印样式。

## 验证

核对两页原有 23 条书目及活动记录保留情况、HTML 标签嵌套、重复 ID、本地资源与锚点；检查 JS 语法与 Git 空白错误。浏览器检查桌面和手机布局、规则切换、引用展开与复制反馈，以及搜索、空结果和清除状态。

Alpha 目录随网站一同发布即可访问，无需配置 DNS 或新增域名。
